# 使用手册

## 适用场景

这个扩展适合把知乎内容导出到本地继续整理，比如：

- 归档自己写过的文章和回答
- 把知乎内容迁移到 Obsidian、Typora、Notion 或博客
- 保存问题页多个回答用于横向比较
- 把首页推荐、关注流和热榜整理成选题清单

## 支持的页面

| 页面 | 识别方式 | 推荐导出方式 | 结果类型 |
| --- | --- | --- | --- |
| 专栏文章 | `/p/...` | 弹窗或悬浮球 | 单篇 Markdown |
| 单条回答 | `/question/.../answer/...` | 弹窗或悬浮球 | 单篇 Markdown |
| 问题页 | `/question/...` | 悬浮球 | 多回答整合 Markdown |
| 首页推荐 | `/` | 悬浮球 | 信息流列表 Markdown |
| 关注动态 | `/follow` | 悬浮球 | 信息流列表 Markdown |
| 热榜 | `/hot` | 悬浮球 | 热榜清单 Markdown |

## 基本使用流程

### 方式一：通过弹窗导出

1. 打开支持的知乎页面。
2. 点击浏览器工具栏中的扩展图标。
3. 等待弹窗识别页面类型、标题和作者。
4. 点击 `导出 Markdown` 下载，或点击 `复制 Markdown` 写入剪贴板。

单篇文章和单条回答最适合直接使用弹窗。复制不会打包图片，Markdown 里保留远程图片地址。

### 方式二：通过悬浮球导出

1. 打开支持的知乎页面。
2. 确认右下角出现悬浮导出按钮。
3. 点击悬浮球下载。右键悬浮球复制 Markdown。
4. 信息流和热榜会滚动加载；问题页会向知乎回答接口继续取回答。

### 方式三：快捷键

在支持的页面按 `Alt+Shift+K`（macOS 上为 Option+Shift+K）导出当前页（新安装的默认键；已安装用户保留原有快捷键，以弹窗显示为准）。弹窗底栏显示「快捷键未设置」时，点「去设置」打开浏览器的快捷键设置页自行指定。

问题页、首页推荐、关注动态和热榜页建议优先使用悬浮球。

## 设置项说明

### 悬浮导出按钮

- 开启后，在支持页面右下角显示悬浮球
- 支持拖拽位置、靠边停靠和位置记忆
- 关闭后会立即移除当前页面上的悬浮球

### 最大下载回答数

- 默认值是 `20`
- 问题页和信息流都使用这个上限
- 设为 `0` 时，问题页尽量全部下载，信息流滚到没有新卡片为止，都最多 1000 条
- 问题页或信息流没下完时（信息流指页面上还有卡片被上限截掉），文首写 `truncated: true`
- 页面或接口给出的内容更少时，导出结果会少于设置值

### 下载图片到本地

- 影响专栏、单条回答，以及问题页的下载导出
- 复制导出不打包图片，Markdown 里保留远程图片地址
- 信息流和热榜不打包图片
- 开启后，符合条件的下载不再输出单独 `.md` 文件，而是输出 ZIP
- ZIP 中包含：
  - 一个 Markdown 文件
  - 一个 `images/` 文件夹
- Markdown 中图片路径会变为 `images/xxx.jpg`

## 每种页面的导出结果

### 专栏文章 / 单条回答

输出内容包括：

- YAML Front Matter
- 标题、作者、原始链接
- 导出日期
- 文章创建时间和编辑时间
- 转换后的正文 Markdown

### 问题页

输出内容包括：

- 问题标题和问题描述
- 导出日期
- `answer_count`
- 没下完时的 `truncated: true`
- 每条回答的作者、时间和正文

问题页通过知乎回答接口继续向后取回答。接口中断时，用页面上已经出现的回答补齐。

### 首页推荐 / 关注动态

输出内容包括：

- 页面类型标题
- 导出日期
- `item_count`
- 每条内容的标题、作者、时间、原文链接和正文摘录

导出器只点击「阅读全文」「展开」或「显示全部」。有链接时按链接去重，没有链接的想法不写空的原文链接。相对时间会保留。

### 热榜

输出内容包括：

- 热榜标题
- 导出日期
- `count`
- 每条热榜的排名、标题、链接、热度

## Markdown 转换规则

扩展内置了一套面向知乎页面的 Turndown 规则，主要包括：

- 公式：行内公式转为 `$...$`。单独成段的公式转为 `$$...$$`
- 图片：优先用 `data-original` 等高清地址，并跳过 `data:` 占位图
- 代码块：转换为 fenced code block
- 链接卡片：可见标题还在加载时，改用链接上的 `data-text`
- 表格：转换为 Markdown 表格
- 视频：保留 `<video>` 或视频卡片的可点击链接
- 换行、分隔线、常见格式标签：按 Markdown 语义输出

## 结果示例

### 单篇内容 Front Matter

```yaml
---
title: "示例标题"
url: "https://www.zhihu.com/question/..."
author: "示例作者"
date: 2026-03-31
created: "2025-12-01"
edited: "2025-12-03"
---
```

### 多回答导出头部

```yaml
---
title: "示例问题"
url: https://www.zhihu.com/question/...
date: 2026-03-31
answer_count: 12
truncated: true
---
```

`truncated` 只在问题页或信息流没有下完时出现。

## 已知限制

- 问题页会继续向知乎回答接口取后续回答，但仍受条数上限约束
- 回答接口失败时，只保留页面上已经出现的回答
- 默认不会抓取评论区
- 被折叠、未展开或受权限限制的内容，只有在页面中实际可见时才可能被导出
- 知乎改版后，选择器可能需要同步更新
- 信息流和热榜不打包图片。问题页只有下载导出才会打包
- 弹窗触发的长导出需要让弹窗保持打开，直到下载开始
